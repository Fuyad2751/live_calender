# Live Calendar Pro

একটি প্রফেশনাল লাইভ ক্যালেন্ডার অ্যাপ্লিকেশন যাতে বাংলা, ইংরেজি ও আরবি ক্যালেন্ডার রয়েছে।

## বৈশিষ্ট্যসমূহ
- 🌍 তিনটি ক্যালেন্ডার: বাংলা, ইংরেজি, আরবি
- 🌅 রিয়েল-টাইম সূর্যোদয় ও সূর্যাস্ত
- 🌙 ডার্ক/লাইট থিম
- ☀️ ডাইনামিক সূর্য ও চন্দ্র এনিমেশন
- 📱 সম্পূর্ণ রেসপনসিভ ডিজাইন

## ব্যবহার প্রযুক্তি
- HTML5
- CSS3 (Glass Morphism, Animations)
- Vanilla JavaScript
- Sunrise-Sunset API

## কীভাবে ব্যবহার করবেন
1. রিপোজিটরি ক্লোন করুন
2. index.html ফাইল ব্রাউজারে খুলুন
